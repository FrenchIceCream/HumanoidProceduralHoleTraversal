A system that uses procedural animation to make humanoid characters traverse holes.

### Requirements
- Unreal Engine 5.7
- Control Rig Physics plugin

### Setup
- Clone the repository and open .uproject file. You will be prompted to build the project, click OK.
- To customise default character, navigate to BP_AnimatedCharacter and change the character to your liking. Retarget animations from ABP_AnimatedCharacter using your character's skeletal mesh and set new ABP to the corresponding slot in BP_AnimatedCharacter.
- Your character should be ready to go after these steps, but you can fine-tune it by going into Anim Graph of your ABP and changing control rig parametres.
